# Liliana Bravo — Home portfolio prototype

Responsive, bilingual (English/Spanish) static home page made with vanilla HTML, CSS and JavaScript for GitHub Pages.

## Preview

Open `index.html` in a browser. The website works without a build process. Google Fonts require internet, but fallback fonts are available.

## Publish on GitHub Pages

1. Upload `index.html`, `styles.css`, `script.js`, and the complete `assets/` folder to the repository root (`relibrana/portfolio`).
2. Open your repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, `main` and `/(root)`, then save.
4. Visit `https://relibrana.github.io/portfolio/` once GitHub finishes deploying.

## Prototype scope

- Responsive hero, navigation, work grid, project filters, about, community, interactive Harumi, contact
- EN/ES toggle saved in browser local storage
- Working outgoing project and social links
- User-provided photographs credited to their original creator (no AI-generated portraits)
- Conceptual graphics for project cards, **not actual game screenshots**
- Individual case-study pages are planned for the next phase and are not yet implemented.

## Files

- `index.html`: content and structure
- `styles.css`: visual design and responsive styles
- `script.js`: language toggle, project filters, mobile menu, Harumi's heart animation
- `assets/`: user-provided photography
